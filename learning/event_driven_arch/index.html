  3. Weaknesses and Failure Modes — the shadow side of every strength above
  4. Mitigation Strategies — a named fix for each weakness, and the trade-off it introduces
  5. The Log as Source of Truth — flipping the outbox: what changes (and what doesn't) when the topic, not the database, is authoritative
  6. Case Studies: Successes and Failures — Netflix, Shopify, and Uber next to Knight Capital, PagerDuty, and a duplicate-delivery postmortem
