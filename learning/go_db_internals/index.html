Database Internals in Go

CMU 15-445/645 Database Systems (Fall 2025), rebuilt in Go. You'll cover every lecture topic and every homework, then implement all four BusTub projects yourself: a buffer pool manager, a B+tree index, a query execution engine, and MVCC concurrency control.

Each lesson opens with a quick retrieval quiz on earlier material, teaches the database concept with slides and lecture clips from the CMU course, and ends with homework-style questions. Project lessons then break the CMU project into stages. You implement each stage yourself in Go and check it with go test, and the hints never show the full solution. Lesson 0 gets the code onto your Mac.

Unit 0: Orientation & SQL

  1. Setup: Sparse Checkout, Go, and a Tour of the Code: get only the course's Go code from the repo, install the toolchain, and see how the codebase maps onto the CMU projects
  2. The Relational Model & Relational Algebra (lecture #01)
  3. Modern SQL (lecture #02): aggregates, joins, nested queries, window functions, CTEs
  4. HW1 Hands-On, Part 1: DuckDB, the Lahman Database, and Q1–Q3: CMU's SQL homework against the real dataset, checked against the official answers
  5. HW1 Hands-On, Part 2: Q4–Q6
