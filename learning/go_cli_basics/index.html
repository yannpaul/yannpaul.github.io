Go Basics Through a CLI Tool

Learn Go by building burrow — a nested-subcommand CLI (burrow find name --pattern "*.go") that finds files, reports disk usage like ncdu, and inspects file permissions. Every lesson is a checklist, not a script: what to build, never the code itself, with hints hidden behind collapsed disclosures for when you're stuck.

Twelve lessons, each a self-contained page. Every lesson (from Lesson 2 on) opens by making you redo everything structural from prior lessons before teaching anything new — that repetition is deliberate, not filler. Only Lessons 1–4 are written so far; the rest are scoped below and will be built out in future sessions.

Lessons

  1. A Module, a Main, and the Shape You'll Reuse — set up your first Go module and a runnable main, then adopt the getConfig/run split you'll rebuild in every remaining lesson
  2. Reading Arguments Without Being Shown Them — rebuild Lesson 1 from memory, then use the standard library's flag package to capture a -path flag into a Config
  3. Walking a Directory Tree — rebuild Lessons 1–2 again, then use filepath.WalkDir to make burrow print every file under a path, the rough draft find will refine
  4. Nested Subcommands, By Hand — dispatch on os.Args and give each of find, du, and perm its own flag.NewFlagSet — the first real foo bar --arg val shape
  5. Coming up — Matching Names and Globs — use filepath.Match to implement burrow find name --pattern for real, three levels deep (foo bar baz --arg val)
  6. Coming up — Sizes, Sorting, and Structs — sum directory sizes recursively into a small struct, sort them, and implement burrow du top --n as an ncdu-style report
  7. Coming up — Permission Bits — read os.FileMode and use bitwise checks to implement burrow perm check for read/write/execute
  8. Coming up — Who Owns This File — use os/user to implement burrow perm who, and the platform caveats that come with it
  9. Coming up — Three Levels Deep — refactor the whole by-hand dispatcher into one clean find name/find size/du top/perm check/perm who tree
  10. Coming up — Upgrading to Cobra — rebuild the same command tree with spf13/cobra, the real-world library answer to "configure and capture command-line arguments," and compare it to Lesson 4's by-hand version
  11. Coming up — Testing What You Built — write table-driven go test cases for the pure functions underneath find, du, and perm
  12. Coming up — Capstone: Polish and Recap — add proper --help text, go install it for real, and redo the full course's structural checklist from memory in one pass
