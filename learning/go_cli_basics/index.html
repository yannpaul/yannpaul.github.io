Go Basics Through a CLI Tool

Learn Go by building burrow — a nested-subcommand CLI (burrow find name --pattern "*.go") that finds files, reports disk usage like ncdu, and inspects file permissions. Every lesson is a checklist, not a script: what to build, never the code itself, with hints hidden behind collapsed disclosures for when you're stuck.

Thirteen lessons, each a self-contained page. Every lesson (from Lesson 2 on) opens by making you redo everything structural from prior lessons before teaching anything new — that repetition is deliberate, not filler. All thirteen are now written; the course is complete. Go Concurrency Through burrow picks the same codebase back up with goroutines and channels, if you want to keep going.

Lessons

  1. A Module, a Main, and the Shape You'll Reuse — set up your first Go module and a runnable main, then adopt the getConfig/run split you'll rebuild in every remaining lesson
  2. Reading Arguments Without Being Shown Them — rebuild Lesson 1 from memory, then use the standard library's flag package to capture a -path flag into a Config
  3. Walking a Directory Tree — rebuild Lessons 1–2 again, then use filepath.WalkDir to make burrow print every file under a path, the rough draft find will refine
  4. Nested Subcommands, By Hand — dispatch on os.Args and give each of find, du, and perm its own flag.NewFlagSet — the first real foo bar --arg val shape
  5. Matching Names and Globs — use filepath.Match to implement burrow find name --pattern for real, three levels deep (foo bar baz --arg val)
  6. Sizes, Sorting, and Structs — sum directory sizes recursively into a small struct, sort them, and implement burrow du top --n as an ncdu-style report
  7. Making Failures Visible — stop silently discarding errors (and see why go vet won't catch it for you), then use print debugging and delve for what's left
  8. Permission Bits — read os.FileMode and use bitwise checks to implement burrow perm check for read/write/execute
  9. Who Owns This File — use os/user and syscall.Stat_t to implement burrow perm who, and the platform caveat that comes with it
  10. Cleaning Up the Dispatch — notice the repeated flag-set boilerplate across find/du/perm's dispatchers and extract it into one shared helper, deliberately stopping short of a bigger hand-rolled registry
  11. Upgrading to Cobra — rebuild the whole command tree with spf13/cobra, the real-world library answer to "configure and capture command-line arguments," and get real generated --help text for free
  12. Testing What You Built — write a table-driven go test for a pure helper and a t.TempDir()-based test for one that touches disk
  13. Capstone: Polish and Recap — add proper --help text, go install it for real, and redo the full course's structural checklist from memory in one pass
