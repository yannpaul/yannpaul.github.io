Capstone: Polish and Recap

Two small finishing touches. Then the whole course, from memory, with almost no hints left to lean on.

burrow already does everything it set out to do. Today: make its --help text actually explain itself, install it so it runs from anywhere without go run or a relative path, and then one long checklist — every idea from Lessons 1 through 12, in order, mostly without the safety net.

New: real --help text

Right now burrow --help lists find, du, and perm with no description next to any of them — Cobra shows whatever you gave it, and you never gave it anything. A Short field on any *cobra.Command is a one-line description shown in exactly that listing.

  • Stuck? Show one example 
    rootCmd := &cobra.Command{
	Use:           "burrow",
	Short:         "burrow finds files, reports disk usage, and inspects permissions",
	SilenceErrors: true,
	SilenceUsage:  true,
}

    Write your own wording for the rest — a short, accurate sentence for each, the same as you'd want to read if you'd never seen this tool before.

    Checkpoint

    burrow --help now shows a one-line description next to every command. burrow find --help shows one next to name.

  • Stuck? Show the field 
    Version: "0.1.0",
    Checkpoint

    burrow --version (and its shorthand, burrow -v) now prints it — a flag you never registered yourself. Cobra adds it automatically the moment Version is non-empty.

New: installing it for real

  • Stuck? Show the command 
    go install .
    Checkpoint

    A burrow binary now exists at $(go env GOPATH)/bin/burrow — check with ls $(go env GOPATH)/bin. If that directory is on your shell's PATH (a one-time setup step this lesson can't do for you — it's specific to your shell and OS), you can now run burrow find name --pattern "*.go" from any directory, with no go run, no ./, no rebuilding.
