New: reading permission bits

os.Stat(path) returns an fs.FileInfo; its .Mode() method returns an fs.FileMode — a bitmask. The bottom nine bits are the familiar Unix permission bits, three groups of three: owner, group, other, each read/write/execute. In octal, those are 0400/0200/0100 for owner read/write/execute, 0040/0020/0010 for group, and 0004/0002/0001 for other. To check whether a given bit is set, bitwise-AND the mode against that constant: if the result is nonzero, the bit is set.

  • Build a []string, append conditionally on each bitwise-AND check, then join it — this is a good place to reach for strings.Join rather than hand-building a string with trailing separators.

    Stuck? Show the function 
    func perms(mode os.FileMode, r, w, x os.FileMode) string {
	var parts []string
	if mode&r != 0 {
		parts = append(parts, "read")
	}
	if mode&w != 0 {
		parts = append(parts, "write")
	}
	if mode&x != 0 {
		parts = append(parts, "execute")
	}
	if len(parts) == 0 {
		return "(none)"
	}
	return strings.Join(parts, ", ")
}

    Add "strings" to your import block.

  • Stuck? Show the function 
    func checkPerm(path string) error {

Idiom

fs.FileMode packs more than just the nine permission bits — the high bits encode whether it's a directory, a symlink, and other special file types, which is exactly what d.IsDir() (Lesson 3) checks under the hood. Printing a FileMode directly with %s or fmt.Println gives you the familiar ls -l-style string (-rw-r--r--) for free, since FileMode has its own String() method — worth trying as a sanity check while you're testing above, even though today's perms helper reports the same information a different way on purpose, since the bitwise-AND technique is the actual point of this lesson.

perm check is real now. Lesson 9 gives perm a second verb — who — to answer a question permission bits alone can't: whose file this actually is.
