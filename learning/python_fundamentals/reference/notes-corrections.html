Where the Notes and Python Differ

Every line in your class notes was checked by running it. Almost all of it was right. These are the few places where real Python behaves differently, so you are not surprised.

If a test asks you for the class answer and Python gives a different one, ask your teacher which to give. Whenever a short program can show the answer, run it in the course. Python is always right about what Python does.

Your noteWhat Python really doesLesson
Operator ladder: containment, then comparison, then identity, as separate levels They are one level, evaluated left to right, and they chain. 5 in [1, 5] == True is False. 2
Arithmetic: + - * / % listed as one level Inside arithmetic, ** goes first, then * / // %, then + -. 1
Floor division “returns the integer value” It rounds down (-7 // 2 is -4) and returns a float if either number is a float (7.0 // 2 is 3.0). 4
math.sqrt of a negative returns NaN It raises ValueError: math domain error. 5
math.sqrt(25) returns “5 (or 5.0)” Always 5.0, a float. Likewise math.pow and math.fabs. 5
math.PI or math.pi “depending on the language” In Python it is only math.pi. 5
import datetime then datetime.now() That is an AttributeError. Use from datetime import datetime for datetime.now(), or write datetime.datetime.now(). 6
Unit test example: assertEqual(2 + 8, a + b) with a = 3, b = 6 The code is the right shape, but the test fails: 10 is not 9. 8
“A with statement removes a file from memory” It closes the file when the block ends. 9
File question: workFileFirstLine = workFile.read() The class answer is read(), but read() returns the whole file. The first line alone would be readline(). 9
