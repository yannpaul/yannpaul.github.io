Operator Precedence

Highest first. Print it, and tick off the rung as you work out a line.

▲ Happens first

  1. Parentheses ( )
  2. Power ** tied ones go right to left
  3. Sign -x
  4. Multiply, divide, floor-divide, remainder * / // %
  5. Add, subtract + -
  6. Containment, comparison, identity in, not in, < <= > >= == !=, is, is not one rung in real Python; they chain
  7. Logical not not
  8. Logical and and
  9. Logical or or
  10. Assignment = += -= *= /= //= %= always last

▼ Happens last

The three-step habit

  1. Circle the operators.
  2. Rank them with the ladder.
  3. Do the highest first. Ties go left to right (except **). Assignment is last.

Shorthand assignment

WriteMeans
a += ba = a + b
a -= ba = a - b
a *= ba = a * b
a //= ba = a // b

Whatever is to the right of the operator is worked out first: a *= b + 3 is a = a * (b + 3).

Division family

ExpressionResult
17 / 53.4 (always a float)
17 // 53 (round down)
17 % 52 (remainder)
-7 // 2-4 (down, not toward zero)
7.0 // 23.0 (float in, float out)

Traps

  • 2 + 3 * 4 is 14. (2 + 3) * 4 is 20.
  • 10 - 4 - 3 is 3 (left to right).
  • 2 ** 3 ** 2 is 512 (right to left). -2 ** 2 is -4.
  • True or False and False is True, because and goes first.
  • 5 in [1, 5] == True is False: they chain. Add parentheses.
