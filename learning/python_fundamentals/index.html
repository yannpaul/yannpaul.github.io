Python Fundamentals

A Python course built from your own class notes, with a real Python interpreter on every page, a step-by-step walkthrough for every kind of problem, and a bank of practice questions with tips. It grows each time you bring new material from class.

How this course works

Every lesson takes about 20 to 25 minutes. It explains one idea from your notes, lets you run real Python right on the page, and finishes with practice problems.

Every problem has tips that get bigger one at a time, an explanation of why, and a full walkthrough that steps through the code line by line, showing what each name holds, like Python Tutor.

The first time you press Run, the page loads Python (about 10 MB), so it needs an internet connection that one time.
