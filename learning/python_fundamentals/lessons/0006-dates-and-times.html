Dates and Times

Import the right thing, build a date, turn it into text with strftime, and find the day of the week.

⏱ about 20 min ▶ code you can run on this page

Warm-up: from last time

Two questions from earlier lessons, from memory. Spacing out your practice like this is what makes it stick.

Programs are always asking “what day is it?” and “what should I print on this invoice?”. The datetime module answers both.

Which import?

This module has a confusing habit: the module is called datetime and the main class inside it is also called datetime. Which one the name means depends on how you import.

You writeThe name datetime meansCurrent time
from datetime import datetimethe classdatetime.now()

A note that does not work as written

Your notes list import datetime and then datetime.now(). Those two do not go together: import datetime followed by datetime.now() is an AttributeError, because the module has no now. The class does. Use from datetime import datetime for the short form. There is an exam-trap problem about this below.

The tools from your notes

ToolWhat it does
datetime.now()the exact current local date and time, from your computer
d.strftime(format)“string format time”: turns a date into text, using % codes
d.weekday()the day of the week as a number: Monday is 0, Sunday is 6

weekday is a method, so it needs parentheses: d.weekday().

The format codes you need

Capital and lowercase mean different things. A good way to remember: the capital letter is usually the longer, fuller version.

Try it

from datetime import datetime

d = datetime(2024, 3, 5, 14, 7)
print(d.strftime("%Y-%m-%d"))
print(d.strftime("%A, %B %d, %Y"))
print(d.strftime("%I:%M %p"))
print(d.weekday())

print(datetime.now())

The last line shows the real current time, so it changes every time you press Run.
