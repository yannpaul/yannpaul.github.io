Files and sys.argv

Open a file for reading, writing or appending, check that it exists, and read what you typed on the command line.

Warm-up: from last time

Two questions from earlier lessons, from memory. Spacing out your practice like this is what makes it stick.

Programs that remember things need files. This lesson covers the three modes of open, why a with block is tidy, how to check a file is there, and what sys.argv holds.

Opening a file: the mode letter

ModeMeansIf the file already exists
'r'read (the default)opens it, you can only read
'w'writeerases it and starts again
'a'appendkeeps it, adds new text at the end

This is the heart of the class question about the daily log. open('log.txt', 'w') wipes the file each time it is opened. Use 'a' to build up a log.

with: open and close for you

with open('log.txt', 'a') as file:
    file.write('Daily Log\n')
# the file is closed here, automatically

A with block closes the file when the block ends, so file.close() is not needed. Your notes say it “removes the file from memory automatically”. More exactly, it closes the file.

Reading

CallGives
f.read()everything that is left in the file, as one string
f.readline()one line, including its newline character
f.seek(n)moves the reading position to character n (it returns nothing to read)

The reading position moves forward as you read, so a second call carries on where the first one stopped.

Does the file exist?

os.path.exists('work.txt') is True or False. Check before reading a file you did not create.

Try it: write, append, read

Files here live in a scratch area inside your browser tab, so you cannot damage anything on your computer.

import os.path

with open("log.txt", "w") as f:
    f.write("one\n")
with open("log.txt", "a") as f:
    f.write("two\n")

if os.path.exists("log.txt"):
    with open("log.txt") as f:
        print(f.read())
else:
    print("The file is not in this folder.")

sys.argv: what you typed after python

When you start a program with python app.py 5 hello, Python collects the words into a list called sys.argv:

IndexHolds
sys.argv[0]'app.py', the file name of the script (the answer to your “idk this”)
sys.argv[1]'5' (text, not a number!)
sys.argv[2]'hello'

The box below pretends the command was python app.py 5 hello.

import sys

print(sys.argv)
print(sys.argv[0])
print(len(sys.argv))
print(sys.argv[1] + sys.argv[1])
print(int(sys.argv[1]) + int(sys.argv[1]))
