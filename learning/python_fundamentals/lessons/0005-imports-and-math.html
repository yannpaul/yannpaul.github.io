Python comes with a big toolbox of ready-made code, split into modules. You import the ones you need. This lesson covers how to import, which modules your notes mention, and the math functions.

Three ways to import

LineWhat it doesHow you use it
import mathBrings in the whole modulemath.sqrt(9) (dot notation)
from math import sqrtBrings in one namesqrt(9) (no prefix)
import random as rdWhole module, with a nickname (alias)rd.randint(1, 6)

With an alias, the old name is gone: after import random as rd, writing random.randint gives a NameError.

The math module

ToolResultExample

Checked against real Python

1. math.sqrt(-1) does not return NaN in Python. It raises ValueError: math domain error. Run it below to see.

2. Python's constant is math.pi, lowercase only. Your note about math.PI “depending on the language” is about other languages. In Python, math.PI is an AttributeError.

3. These functions return floats. math.sqrt(25) is 5.0, never plain 5. Your note says “or 5.0 in many languages”. In Python it is always 5.0. The same goes for math.pow and math.fabs.

4. Your note on round() is right. It is built in, there is no math.round, and a tie such as round(2.5) goes to the even number, 2.

Try it

import math

print(math.sqrt(25))
print(math.floor(-3.5), math.ceil(-3.5), math.trunc(-3.5))
print(math.pi)
print(round(2.5), round(3.5))

try:
    print(math.sqrt(-1))
except ValueError as e:
    print("ValueError:", e)
