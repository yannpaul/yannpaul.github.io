Division, Floor and Remainder

Three ways to divide: /, // and %. Plus the power operator, and the traps that appear with negative numbers.

⏱ about 20 min ▶ code you can run on this page

Warm-up: from last time

Two questions from earlier lessons, from memory. Spacing out your practice like this is what makes it stick.

Dividing 17 sweets between 5 children has three useful answers: 3.4 sweets each (/), 3 whole sweets each (//) and 2 sweets left over (%). Python has an operator for each.

The operators

OperatorName17 and 5 gives
17 / 5true division3.4 (always a float)
17 // 5floor division: divide, round down3
17 % 5modulus: the remainder2
17 ** 2power289

Your notes: modulus (%) returns the remainder after division. Floor division (//) rounds down and returns the integer value. Two small details to add to that second one:

Two details about //

1. It only returns an int if both numbers are ints. 7.0 // 2 is 3.0, a float that has been rounded down.

2. “Down” means toward the smaller number, not toward zero. -7 // 2 is -4, because -4 is below -3.5. This one is on a lot of tests.

They fit back together

// and % are two halves of one idea. For any numbers: a == (a // b) * b + a % b. So 17 is 3 fives plus 2.

The classic use is splitting up a quantity. 135 minutes is how many hours and minutes? Step through to see it.

Try it

print(17 / 5)
print(17 // 5)
print(17 % 5)
print(-7 // 2)
print(-7 % 3)
print(7.0 // 2)
Remember

*, /, // and % are all tied, so a line such as n // 10 % 10 goes left to right: first n // 10, then % 10. Strip off the last digit, then keep the next one.
