Errors: try, except, raise, finally

Catch errors instead of crashing. Learn which block runs when, and how to throw an error on purpose.

Things go wrong: a file is missing, someone divides by zero. Error handling lets your program decide what to do. This is the last practice question in your notes.

Four blocks, one rule each

BlockRuns when…
try:always starts here. If a line raises an error, the rest of the block is skipped.
except:the try block raised an error (a matching one)
else:the try block finished with no error
finally:always, whatever happened. It goes last.

raise is the keyword that throws an exception on purpose, so the calling code can catch it. It is a keyword, not a method, and throw is the Java word for the same idea.

Watch the two paths

The same program, once without an error and once with one. Step through both and compare which blocks run.

Your class program

This is the code from your notes. The box below gives it two inputs, 10 and 2. Run it, then change the second input to 0 and run again.

x = float(input("Enter a number. "))
y = float(input("Enter a number to divide by. "))

try:
    print(f"The answer is {x/y}.")
except:
    if y == 0:
        raise Exception("You cannot divide by zero")
finally:
    print("Thank you for playing.")

With 0 you will see two things: “Thank you for playing.” is printed even though the program is about to fail, and then the error is reported. That is finally.

Catch the error you expect

A bare except: catches everything, including mistakes you did not mean to hide. It is better to name the error: except ZeroDivisionError:. Then a surprise, like a typo, still shows up.
