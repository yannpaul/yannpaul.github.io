context.Context in Go

Learn Go's context package by replacing a real hand-rolled timeout in burrow, the CLI tool from Go CLI Basics, with the real thing. Same format as the other Go workspaces — a checklist, not a script, with code hidden behind collapsed disclosures until you're stuck.

Seven lessons, each a self-contained page. Every lesson (from Lesson 2 on) opens by making you redo everything structural from prior lessons before teaching anything new. All seven are now written; the course is complete. Go Concurrency Basics' Lesson 6 built duTop a timeout using a bare select and time.After, and named context.WithTimeout as the natural next step — this workspace is that next step, and assumes you already have a working burrow with that lesson's timeout in place.

Lessons

  1. What context.Context Is For — the Done() channel, context.WithCancel, and watching a goroutine unblock the moment it's canceled, on a small standalone demo before touching burrow
  2. WithCancel and WithTimeout on duTop — replace go_concurrency_basics' hand-rolled select/time.After timeout with a real context.WithTimeout, propagated in from main
  3. Propagating Context Through Call Chains — context trees: a child context created from a parent, why canceling the parent cancels every child automatically, and wiring a real one into burrow via Cobra's ExecuteContext
  4. Cancellation on Interrupt — wire a real Ctrl+C, via os/signal.NotifyContext, to cancel a long-running du top from outside
  5. context.WithValue — what it's for, why it's narrowly scoped to request-scoped metadata, and a real, demonstrated key-collision bug from overusing it
  6. Context and errgroup — errgroup.WithContext: canceling sibling goroutines the moment one of them fails, measured against go_concurrency_basics' plain errgroup.Group
  7. Capstone — pull every technique together, measure the concrete payoff, and defend every cancellation/timeout decision in the finished code plus one open-ended design question
