Bouncing Square in Pygame

A one-lesson proof of concept: build a square that bounces around the screen forever, entirely in the browser at onecompiler.com — no Python or pygame install needed. One checklist, one working program, one satisfying win.

Unlike this repo's other, multi-lesson workspaces, this one is a single self-contained lesson. If it goes well and there's an appetite to keep learning pygame past the bouncing square, this workspace can grow into a full course from here.
