Functions, Tests, Files and Errors

The patterns from the Day 2 practice questions, side by side.

Function

def calcSubtotal(amount, salesTaxRate):
    subtotal = amount * (1 + salesTaxRate)
    return subtotal

def, name, parameters in parentheses, colon, indented body, return. No return gives back None.

Unit test

import unittest
class Test_Example_UnitTest(unittest.TestCase):
    def test_equal(self):                    # name must start with "test"
        self.assertEqual(2 + 8, 10)
if __name__ == '__main__':
    unittest.main()
assertEqual(a, b)a == b
assertIs(a, b)a is b (same object / same memory)
assertTrue(x)x is true
assertIn(a, b)a in b

An assert says “this must be True”. If not, an AssertionError is raised and the test fails.

Files

ModeMeans
'r'read (default)
'w'write: erases an existing file
'a'append: adds at the end
import os.path
if os.path.exists('work.txt'):
    with open('work.txt', 'r') as f:     # with closes the file for you
        text = f.read()                  # read() = all, readline() = one line
else:
    print("The work file is not in this folder.")

sys.argv for python app.py 5 hello is ['app.py', '5', 'hello']. Index 0 is the script name. Everything is text.

Errors

try:
    print(x / y)
except ZeroDivisionError:      # runs only if the try raised this error
    raise Exception("You cannot divide by zero")
else:                          # runs only if the try had no error
    print("worked")
finally:                       # always runs, last
    print("Thank you for playing.")

raise throws an exception (Java says throw). except catches (Java says catch).
