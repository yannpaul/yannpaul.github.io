A function is a named recipe. Write it once, use it as often as you like. This is the first practice question from your notes: calcSubtotal.

The anatomy

def calcSubtotal(amount, salesTaxRate):         # header: def, name, parameters, colon
    subtotal = amount * (1 + salesTaxRate)      # body: indented four spaces
    return subtotal                             # hand the answer back
  • def is the keyword that says a function is being built.
  • Parameters are the placeholder names in the header: amount and salesTaxRate. They go in parentheses, and the header ends with a colon.
  • The indented lines are the body. They run only when the function is called.
  • return sends a value back to whoever called the function, and ends the function there.
  • Arguments are the real values you pass in at the call: calcSubtotal(100, 0.25).

The subtotal is the amount calculated, so subtotal is what is returned, not amount and not the name of the function.

See what happens at a call

Step through a tiny function. Defining it does nothing. The call is what makes a new frame appear.

Try it

Press Step through and watch the frames. Notice the “Return value” box.

def calcSubtotal(amount, salesTaxRate):
    subtotal = amount * (1 + salesTaxRate)
    return subtotal

print(calcSubtotal(100, 0.25))
print(calcSubtotal(80, 0.1))

Three things that catch people

  1. No return means None. A function that only calculates, without return, gives back nothing useful.
  2. return ends the function. Lines after it never run.
  3. A name made inside a function stays inside. Setting x = 5 in a function does not change a global x.
Return or print?

print shows something on the screen. return hands a value to the code that called the function, so it can use it for more calculating. Functions that calculate should return.
