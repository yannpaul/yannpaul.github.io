Unit Tests

Test code with code. What an assert is, how a unittest class is built, and why if __name__ == '__main__' is there.

A unit test is a small piece of code that checks another piece of code does what you expect. Your notes ask “what is an assert test?”. This lesson answers that.

An assert is a promise

assert says: “this must be True”. If it is True, nothing happens. If it is False, Python raises an AssertionError. A test fails when an assertion fails.

assert 2 + 2 == 4
print("passed")

The unittest module

unittest is Python's built-in testing tool. It gives you a class, TestCase, with ready-made assertion methods:

MethodChecksLike
self.assertEqual(x, y)equal valuesx == y
self.assertIs(x, y)the same object (the same memory space)x is y
self.assertTrue(x)x is truebool(x)
self.assertIn(x, y)x is inside yx in y

The names mirror the operators you learned in Lessons 2 and 3. That is why identity (Lesson 3) matters: assertIs is the test for it.

The anatomy of a test file

import unittest                                  # the built-in module
a = 3
b = 6
class Test_Example_UnitTest(unittest.TestCase):  # a test class inherits TestCase
    def test_equal(self):                        # test method names must start with "test"
        self.assertEqual(2 + 8, a + b)           # the assertion
if __name__ == '__main__':                       # run only when this file is launched directly
    unittest.main()                              # find and run every test method
  • A class that builds a unit test passes through unittest.TestCase.
  • __name__ is '__main__' only when you run the file directly, not when another file imports it. That check decides whether to run the tests.
  • unittest only runs methods whose names start with test. A method called check_b is silently skipped.
Press Run on this one

The example in your notes is a good model for the structure, but look at the numbers: 2 + 8 is 10 and a + b is 9. This test fails. That is useful: you get to see what a failing test looks like. Press Run, read the report, then change 2 + 8 to 2 + 7 and run again.

b = 6
